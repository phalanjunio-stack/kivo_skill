# KIVO Skills

Receitas de vídeo para o KIVO: cada uma diz, com números, como montar um tipo de vídeo bom (qual motion, onde, quando, quanto tempo, qual transição e som). Mais as skills de apoio (planejamento, roteiro, motion e revisão).

| Skill | Para quê |
|---|---|
| receita-pessoa-falando | Especialista/médica falando: palavra-chave grande em serif itálico no peito, B-roll no ritmo da fala, fechamento com a marca |
| receita-comercial-aparelho | Comercial sem locução (estilo FoLix): planos-herói, cortes na batida, revelação da marca |
| receita-so-texto | Tipografia cinética: frases escritas palavra a palavra, palavra gigante, cortes na batida |
| receita-editorial-claro | Campanha premium em tema claro (nude/creme), como a arte do EuroPlasma |
| kivo-motion | Qual motion da biblioteca usar em cada momento (destaque_fala, palavra_gigante, escrita_palavras, revelacao_logo) |
| kivo-planejamento, kivo-roteiro, kivo-revisao | Apoio: analisar material e referência, roteiro sem inventar promessa, conferir antes de entregar |

Os motions citados vêm com o KIVO a partir da versão que traz a biblioteca de 27/11/2026.

No KIVO, abra Diretor → equipe/skills, cole https://github.com/phalanjunio-stack/kivo_skill e use Conectar / atualizar. Revise os agentes atribuídos e ative as skills. Atualizações são manuais; a cópia local funciona sem internet. O importador não executa scripts do repositório.

Skills ensinam métodos. Memória guarda preferências. Kit define a marca. Demanda define o vídeo atual. Este repositório não deve receber memórias pessoais, vídeos de clientes, tokens ou projetos.

## Como melhorar uma skill

Edite o SKILL.md correspondente. Teste em um trecho com comparação antes/depois e registre evidência visual e temporal. Use o histórico do GitHub para recuperar versões. Não considere teste técnico como aprovação estética.
